# binarycc R package

## Influence-Based Variance Estimation for Log-Linear and Logistic Regression on Case-Cohort Data

Computation of the influence-based variance estimate following the complete variance decomposition, for parameter estimated from case-cohort data with glmgee or glm commands and log or logit link.

## Installation

Download file binarycc_0.1.2.tar.gz and install locally in R, from the Install button in the Packages pane in RStudio, or with

```
install.packages("~/path_to_file/binarycc_0.1.2.tar.gz", repos = NULL, type = "source")
```
